# Incision 強制梅花制 叫序網站

整理自 Daniel J. Neill《Incision: Forcing Club System》（2019）的叫序資料庫。

- `原始資料/*.xlsx`：七份叫序表（制度總覽、1♣、1♦、高花、1NT、二階開叫、一般約定）
- `python3 build.py`：由 xlsx 產生 `網站/`
- push 到 `main` 後由 GitHub Actions 部署到 GitHub Pages

本站修訂：原文第一、二家 1♦／1♥／1♠／2♣／2♦ 為 10–12 點，本站改為 8–12 點。
原文缺漏與前後矛盾整理在「制度總覽 › 3.待討論」。
